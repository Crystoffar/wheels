# WHEELS 🎰

A recreation of the slot-machine combat mini-game from *Sea of Stars*, built in Godot 4.

## Getting Started

1. Download and install [Godot 4](https://godotengine.org/download)
2. Clone this repo
3. Open Godot → **Import** → select the `project.godot` file
4. Hit **Play** (F5)

## Tech Stack

- **Engine:** Godot 4
- **Language:** GDScript
- **Platforms:** Windows / Mac / Linux + Web (HTML5)
